# Tommy Edition Projektregeln

## Workflow

1. Eine Story = ein Commit.
2. Jeder Commit muss grün getestet sein.
3. Jede Version bekommt einen Git-Tag.
4. Änderungen werden im CHANGELOG dokumentiert.

## Coding Style

- Komplette Dateien statt Schnipsel.
- Fat Model / Thin Controller.
- Vite für alle Frontend-Assets.
- Bootstrap 5 + Bootstrap Icons.
